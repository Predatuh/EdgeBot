Installing it

  1. Tap Download the app above.
  2. Open the file from your notifications, or Downloads.
  3. Android asks whether to allow installs from this browser the first time — say yes, then tap Install.
  4. Play Protect may warn that it doesn't recognise the app. That is what it says about anything not from the Play Store. Tap Install anyway.

If nothing happens when you tap

You are probably in an app's built-in browser, which cannot finish downloads. Long-press the link and choose Open in Chrome — or open Chrome and type this address in yourself:

predatuh.github.io/EdgeBot/get.html

Once it is installed

Open the app and it loads the live Gridiron Ticket — same version as the web and iPhone. You only reinstall for a rare native-shell update, and that file installs over the top at the same link.
